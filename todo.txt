2. [ ] Implement and verify the peripherals
   - [x] Connect ParIO to MMIO. Verify switch/button reads and LED writes

   - [ ] Map the timer registers and verify MMIO reads, writes, and expiry.

3. [ ] Add vectored interrupts
   - [ ] Build an interrupt controller for the timer and an external button.

   - [ ] Synchronize and debounce the button input. Define how the timer
         and button requests are acknowledged.
   - [ ] Assign separate ROM vectors for the timer and button handlers.
   - [ ] Accept interrupts between instructions, after any active LW has
         completed. Save the resume PC in EPC and return with ERET.
   - [ ] Test both sources, simultaneous requests, and exact resumption.

4. [ ] Add CPU exceptions and traps
   - [ ] Define a minimal MIPS32 CP0 interface: EPC for the return address,
         Cause for the reason, and Status for interrupt/exception state.
         Decide which fields software needs to access with MFC0 and MTC0.
   - [ ] Start with signed ADD overflow. Suppress the destination write,
         save the faulting PC and cause, and jump to the exception handler.
   - [ ] Verify overflow, normal arithmetic, and return via ERET.
         Decide next whether to add ADDI/SUB overflow, misaligned accesses,
         unsupported instructions, or explicit trap instructions.
